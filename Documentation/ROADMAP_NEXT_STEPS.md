# 🗺 Дорожная карта и идеи для развития (Roadmap for Next Chat)

В данном документе зафиксированы идеи, архитектурные улучшения и потенциальные функции для продолжения работы над проектом в новом диалоге.

---

## 🚀 Предлагаемые функции для следующего этапа

### 1. ✅ ВЫПОЛНЕНО: Переход на архитектуру Single Attenuation (Исправление кривой громкости)
- **Цель**: Полностью ликвидировать эффект «тихо на 0–50% и резкий взлет на 50–100%» клавиш F11/F12.
- **Выполненная реализация**:
  - При активном аудиопайплайне физический ЦАП (наушники/динамики) выставляется в **1.0 (Full Scale / 0 dB / Unity Gain)** и не модулируется.
  - Регулировка громкости клавишами F11/F12 ослабляет поток **ровно один раз** средствами macOS CoreAudio на входе BlackHole по нативной кривой Apple.
  - Добавлена поддержка Mute (F10) через `kAudioDevicePropertyMute`.
  - При `pausePipeline()` и `stopPipeline()` физическое устройство восстанавливается в `currentSessionVolume`.
- **Файлы**:
  - `Sources/AudioCoordinator.swift`, `Sources/AudioDeviceHelper.swift`.
- **Статус**: Внедрено, протестировано, приложение собрано Universal 2 Binary и обновлено в `/Applications/SpatialAudio.app`.

---

### 2. Запуск при старте системы (Launch at Login)
- **Цель**: Приложение должно автоматически запускаться в фоновом режиме при входе пользователя в macOS.
- **Техническая реализация**: Использование современного API `SMAppService.mainApp.register()` (macOS 13.0+), не требующего устаревших LoginItems или демонов.
- **UI**: Простой тумблер в настройках панели: *«Запускать при входе в систему»*.

---

### 3. Глобальные горячие клавиши (Global Keyboard Shortcuts)
- **Цель**: Управление пространственным звуком без открывания меню.
- **Функции**:
  - Быстрое включение/выключение Spatial Audio (например, `⌥ + ⇧ + S`).
  - Быстрое циклическое переключение профилей (`⌥ + ⇧ + P`).
- **Техническая реализация**: Использование `NSEvent.addGlobalMonitorForEvents` или библиотеки `HotKey`.

---

### 4. Встроенный параметрический эквалайзер (Parametric EQ)
- **Цель**: Индивидуальная компенсация АЧХ конкретных наушников (усиление баса, подчеркивание вокала, сглаживание резких верхов).
- **Техническая реализация**:
  - Встраивание `AVAudioUnitEQ` в цепочку обработки `SpatialEngine` перед Peak Limiter.
  - 5–10 полос фильтрации (Low Shelf, Parametric Peak, High Shelf).
  - Сохранение настроек эквалайзера внутри пользовательских профилей (`SpatialProfile`).

---

### 5. Вертикальное позиционирование (Elevation / 3D Height)
- **Цель**: Трехмерная сцена с эффектом высоты (звук не только вокруг, но и чуть выше уровня глаз или с потолка, как в Atmos).
- **Техническая реализация**:
  - Добавление параметра `elevationAngleDeg` (-30° ... +45°).
  - Расчет координаты $Y = d \cdot \sin(\text{elevation})$ в `SpatialEngine`.

---

### 6. Привязка профилей к устройствам (Device-specific Profiles)
- **Цель**: Автоматическая активация определенного профиля в зависимости от подключенного оборудования:
  - При подключении `UGREEN-BT505` -> автоматически включается профиль *«Кино»* с широкой базой.
  - При подключении проводных студийных наушников -> профиль *«Студия»* с углом 30°.

---

### 7. Ночной режим / Сжатие динамического диапазона (Night Mode Compressor)
- **Цель**: Комфортный просмотр фильмов ночью в наушниках: выравнивание слишком громких спецэффектов (взрывы, выстрелы) и тихой речи персонажей.
- **Техническая реализация**: Интеграция `kAudioUnitSubType_DynamicsProcessor` с мягким коленом (Soft Knee) и регулируемым порогом (Threshold).

---

## 📌 Заметки для разработчика в новом чате
- Сборка: выполните `./build_app.sh` для создания **Universal 2 Binary** (`arm64` + `x86_64`) и установки в `/Applications/SpatialAudio.app`.
- Сертификат: локальный доверенный сертификат `SpatialAudio Local` автоматически создается и привязывается к связке ключей macOS при первой сборке, предотвращая сброс TCC разрешений микрофона.
- Аудиопоток CoreAudio: в рендер-колбэках реального времени (`AURenderCallback`, `AVAudioSourceNode`) строго соблюдается правило **Zero Allocation & Non-Blocking** (никаких `malloc`/`free`, никаких блокирующих файловых записей или системных логов).
- Логирование: функция `debugLog(...)` активна только при `#if DEBUG` и выводит сообщения в стандартный консольный поток без дисковых блокировок.
- Публичный репозиторий: `https://github.com/vladsboev-web/SpatialAudio` (официальный релиз v1.0.0 с готовым архивом `SpatialAudio.zip`).
