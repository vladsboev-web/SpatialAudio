# 🎧 SpatialAudio — Документация проекта

**SpatialAudio** — это нативное легковесное macOS-приложение (работающее в строке меню), которое перехватывает системный звук macOS через виртуальный аудиодрайвер (BlackHole 2ch), обрабатывает его в реальном времени с использованием аппаратного пространственного алгоритма **Apple HRTFHQ** (Head-Related Transfer Function High Quality) и воспроизводит в любые наушники (Bluetooth / проводные) или внешние динамики с ультра-низкой задержкой (~16–17 мс).

## ⚡ Ключевые возможности

1. **Apple HRTFHQ 3D Sound**: Настоящий пространственный звук с естественной локализацией источников (угол 15°–60°, акустика комнаты).
2. **Нативное сохранение громкости (Unity Gain 1:1)**: Истинный уровень 1:1 к системному звуку macOS. Полная двухсторонняя синхронизация системной громкости macOS (BlackHole $\leftrightarrow$ наушники/колонки) предотвращает ограничение громкости и двойное затухание.
3. **Аварийный Peak Limiter на выходе тракта**: Системный лимитер Apple установлен в самом конце аудиоцепочки (после Master Volume) исключительно как невидимый предохранитель от перегрузок ЦАП.
4. **Ультра-низколатентный RingBuffer**:
   - Размер буфера задержки: 768 сэмплов (~16–17 мс) — идеальный lip-sync при просмотре видео и в играх.
   - Двусторонняя субдискретная линейная интерполяция со сглаживанием дрейфа тактовой частоты ($\pm 0.8\%$ max).
   - Никаких щелчков, заиканий и треска.
5. **Бесшовная системная интеграция**:
   - Выбор другого источника в Центре управления macOS автоматически приостанавливает приложение, не сбивая системный выбор.
   - Выбор `BlackHole 2ch` в системе автоматически возобновляет пространственный звук на активных наушниках.
   - Автоматическое отслеживание подключения и отключения Bluetooth-наушников на лету.
6. **CRUD Профилей**:
   - Создание, удаление, переименование и мгновенное переключение неограниченного числа пользовательских профилей.
   - Все параметры сохраняются в `UserDefaults` и восстанавливаются при перезапуске.
7. **Постоянный сертификат подписи кода**:
   - Приложение подписано постоянным локальным сертификатом разработчика `SpatialAudio Local`.
   - Запрос на доступ к микрофону macOS одобряется один раз и больше никогда не появляется при перезапусках.
8. **Элегантный UI в строке меню**:
   - Скрыт из Dock (`LSUIElement = true`).
   - Динамический значок в меню: `person.wave.2.fill` (активно) / `person.wave.2` (пауза) — не конфликтует с системной иконкой наушников.
   - **Контекстное меню по правому клику**: Быстрый запуск/остановка пайплайна и выход из программы (`⌘Q`) через нативное системное `NSMenu`.
   - **Защита от обрезания в полноэкранном режиме**: Окно popover автоматически фиксируется по верхней границе видимой зоны экрана при автоскрытии строки меню macOS.
   - 0% нагрузки на процессор при закрытом всплывающем окне (таймеры уровней громкости отключаются автоматически).

## 💻 Совместимость и системные требования

| Параметр | Поддержка / Описание |
| :--- | :--- |
| **Архитектура процессора** | **Universal 2 Binary**: Полная нативная поддержка **Apple Silicon** (`arm64`: M1, M2, M3, M4 и новее) и **Intel** (`x86_64`) |
| **Операционная система** | **macOS 13.0 (Ventura)**, **macOS 14 (Sonoma)**, **macOS 15 (Sequoia)** и новее |
| **Среда тестирования** | Протестировано и подтверждено на **macOS 13.7.8 (Ventura)** на базе **Intel Core (MacBook Pro)** |
| **Аудиодрайвер** | [BlackHole 2ch](https://github.com/ExistentialAudio/BlackHole) (v0.6.0+) |
| **Наушники и вывод** | Любые Bluetooth-наушники (AirPods, Sony, Bose, Sennheiser, Ugreen и др.), проводные наушники, внешние ЦАП или динамики Mac |
