# 📖 Руководство пользователя SpatialAudio

**SpatialAudio** превращает любые обычные наушники (Bluetooth или проводные) в полноценную персональную акустическую систему с эффектом присутствия на базе алгоритмов Apple HRTFHQ.

---

## 💻 Системные требования
- **Операционная система**: macOS 13.0 (Ventura), macOS 14.0 (Sonoma), macOS 15.0 (Sequoia) или новее.
- **Архитектура**: Apple Silicon (M1/M2/M3/M4) или Intel Mac.
- **Наушники**: Любые Bluetooth-наушники (AirPods, Sony, UGREEN, Bose, Beats) или проводные наушники / внешние динамики.
- **Виртуальный драйвер**: `BlackHole 2ch` (устанавливается один раз).

---

## 🚀 Первоначальная установка

### Шаг 1. Установка виртуального аудиодрайвера BlackHole 2ch
Если драйвер еще не установлен в вашей системе, запустите установочный скрипт в терминале:
```bash
cd "папка_с_проектом"
./install_driver.sh
```
Или установите его через Homebrew:
```bash
brew install blackhole-2ch
```
*Примечание: Если драйвер был только что установлен, перезапустите CoreAudio командой `sudo killall coreaudiod` или перезагрузите Mac.*

### Шаг 2. Сборка и установка приложения
Соберите приложение командой:
```bash
./build_app.sh
```
Скрипт автоматически:
1. Скомпилирует оптимизированный бинарник Swift.
2. Встроит иконку `AppIcon.icns`.
3. Подпишет приложение локальным сертификатом разработчика `SpatialAudio Local`.
4. Установит готовое приложение в системную папку `/Applications/SpatialAudio.app`.

### Шаг 3. Первый запуск и выдача разрешения
1. Запустите приложение из `/Applications/SpatialAudio.app` или через Spotlight.
2. В появившемся системном окне:
   > *Приложение «SpatialAudio» запрашивает доступ к микрофону.*
   Нажмите **«OK»**.
3. Благодаря постоянному сертификату подписи это окно появится **только один раз** и больше никогда не побеспокоит вас.

## 🎛 Работа с интерфейсом

Приложение работает в строке меню (menu bar) рядом с часами. Кликните по значку силуэта с волнами (`person.wave.2`), чтобы открыть панель управления:

### 1. Профили настроек
- **Выпадающий список**: выбор текущего активного профиля (все настройки восстанавливаются мгновенно).
- **Кнопка `+` (плюс)**: создать новый профиль с текущими значениями ползунков.
- **Кнопка `✎` (карандаш)**: переименовать активный профиль.
- **Кнопка `🗑` (корзина)**: удалить выбранный профиль.

### 2. Радар звуковой сцены
- Интерактивная визуализация положения виртуальных левого и правого динамиков относительно вашей головы.
- **Переключатель «Spatial Audio»**:
  - **Включено**: полный 3D-звук Apple HRTFHQ с естественной бинауральной панорамой.
  - **Выключено (Bypass)**: чистое стандартное стерео без пространственной обработки.

### 3. Ползунки акустики
- **Угол колонок (15° — 60°)**:
  - *30°*: Классический идеальный стереотреугольник (рекомендуется для музыки).
  - *45°–60°*: Широкая кинематографическая сцена (идеально для фильмов и сериалов).
  - *15°–20°*: Сфокусированная сцена (отлично для подкастов и аудиокниг).
- **Дистанция (0.5 м — 3.0 м)**:
  - Удаленность виртуальных мониторов от слушателя. Громкость компенсируется автоматически: при отдалении звук не становится тише.
- **Акустика комнаты (0.0% — 3.0%)**:
  - Добавляет ультра-деликатные естественные отражения комнаты прослушивания (Small Room Preset, тонкий шаг 0.1%), устраняя эффект "звука внутри черепа" и делая восприятие мягким.
- **Громкость и Усиление**:
  - Точная подстройка общей громкости и чистого запаса усиления (+2 dB).

## 🔄 Системные сценарии (как переключать звук)

Вам больше **не нужно открывать окно программы** для включения или отключения:

1. **Хотите слушать звук с пространственным эффектом**:
   - В Центре управления macOS (или в строке меню в меню Звука) выберите выход: **`BlackHole 2ch`**.
   - Приложение автоматически возобновит работу и направит обработанный 3D-звук в ваши активные наушники. Значок в строке меню станет залитым (`person.wave.2.fill`).
2. **Хотите слушать обычный звук напрямую (например, через динамики MacBook)**:
   - В меню Звука macOS выберите **«Динамики MacBook Pro»** (или любое другое устройство).
   - Приложение автоматически приостановится (значок станет контурным `person.wave.2`) и не будет мешать прямому выводу звука.

## ❓ Часто задаваемые вопросы (FAQ & Troubleshooting)

### 1. Звука нет после выбора BlackHole?
- Убедитесь, что в меню приложения в поле **«Выход»** выбраны ваши наушники, а не выключенное устройство.
- Проверьте системную громкость на ваших наушниках.

### 2. Снова появилось окно запроса микрофона?
- Проверьте, что в *Системные настройки → Конфиденциальность и безопасность → Микрофон* тумблер напротив **SpatialAudio** включен.
- Убедитесь, что вы собирали проект через `./build_app.sh`, который накладывает сертификат `SpatialAudio Local`.

### 3. Как полностью закрыть приложение?
- Откройте панель SpatialAudio и нажмите кнопку питания с иконкой выключения в правом нижнем углу.
