# 🎧 SpatialAudio for macOS

**Нативное пространственное стерео (Apple HRTFHQ) для любых Bluetooth-наушников без отслеживания головы (Fixed Spatial Audio).**

Приложение работает в строке меню (Menu Bar) macOS, перехватывает стереозвук системы через виртуальный аудиодрайвер `BlackHole 2ch`, обрабатывает его с использованием оригинального бинаурального алгоритма Apple `HRTFHQ` и выводит в ваши наушники или динамики с ультра-низкой задержкой (~16–17 мс).

## 🌟 Ключевые возможности

* **Apple HRTFHQ Engine**: Аппаратный бинауральный рендеринг Apple CoreAudio (эффект AirPods для любых наушников).
* **Фиксированная звуковая сцена**: Звук естественно выносится вперед перед вами, как перед настоящими студийными мониторами.
* **Ультра-низкая задержка (~16–17 мс)**: Идеальная синхронизация звука и артикуляции губ (lip-sync) в видео и фильмах.
* **Субдискретный RingBuffer**: Линейная интерполяция и автокомпенсация дрейфа частот ($\pm 0.8\%$) — чистый звук без треска и щелчков.
* **Автоматическое системное переключение**:
  - При выборе `BlackHole 2ch` в Центре управления macOS пространственный звук включается сам за 300 мс.
  - При выборе встроенных динамиков или другого устройства приложение само уходит на паузу (0% CPU).
* **CRUD Профилей**: Создание, переименование и удаление собственных пресетов акустики, сохраняемых при перезапуске.
* **Постоянный сертификат подписи**: Создан доверенный локальный сертификат `SpatialAudio Local` — системный запрос на микрофон запрашивается ровно 1 раз.
* **Нативная иконка и статус-бар**: Специализированный динамический значок `person.wave.2` (Apple Spatial Audio) и 3D-иконка приложения в стиле macOS Sonoma.

## 📦 Установка

### Вариант 1: Быстрая установка (Готовый релиз)

1. **Установите виртуальный аудиодрайвер BlackHole 2ch** (требуется для перехвата системного звука):
   ```bash
   brew install blackhole-2ch
   ```
   *Либо скачайте официальный инсталлятор `.pkg` с [сайта Existential Audio](https://existential.audio/blackhole/).*

2. **Скачайте приложение**:
   - Перейдите в раздел **[Releases](../../releases)** и скачайте архив `SpatialAudio.zip`.
   - Распакуйте архив и перетащите `SpatialAudio.app` в папку `/Applications` («Программы»).

3. **Первый запуск (Обход macOS Gatekeeper)**:
   Приложение распространяется в открытом доступе без платного сертификата Apple Developer ID ($99/год). Поэтому при первом открытии macOS может показать стандартное предупреждение о неопознанном разработчике.
   
   **Чтобы открыть приложение:**
   - Нажмите по `SpatialAudio.app` **правой кнопкой мыши (или Control + клик)** в папке «Программы» → выберите **«Открыть»** → подтвердите кнопкой **«Открыть»**.
   - *Либо выполните команду снятия карантина в Терминале:*
     ```bash
     xattr -cr /Applications/SpatialAudio.app
     ```

4. **Доступ к микрофону**:
   При первом запуске macOS попросит разрешение на доступ к аудиоустройствам (микрофону). Нажмите **«Разрешить» (OK)** — это необходимо macOS для считывания звука с драйвера BlackHole.

---

### Вариант 2: Сборка из исходников (Для разработчиков)

Если вы хотите собрать приложение самостоятельно на своем Mac:

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/vladislavsboev/SpatialAudio.git
   cd SpatialAudio
   ```
2. Установите драйвер BlackHole (если еще не установлен):
   ```bash
   ./install_driver.sh
   ```
3. Запустите скрипт сборки:
   ```bash
   ./build_app.sh
   ```
   Скрипт автоматически создаст локальный доверенный сертификат `SpatialAudio Local`, скомпилирует приложение, подпишет его и скопирует в `/Applications/SpatialAudio.app`.

## 🎧 Использование

1. Подключите любые наушники (Bluetooth или проводные).
2. В Пункте управления macOS (меню звука) выберите выход **`BlackHole 2ch`**.
3. Значок приложения в строке меню станет активным (`person.wave.2.fill`), и системный звук пойдет через пространственный движок прямо в наушники.
4. Кликните по значку в строке меню, чтобы настроить угол стереобазы, дистанцию виртуальных мониторов и деликатную акустику комнаты (0–3%).
